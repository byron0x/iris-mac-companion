Privacy, permissions and what this check covers

IRIS uses the browser’s management permission to list extensions and perform changes you choose here. Storage remembers your review choices, reversible changes and optional web connection in this browser profile.

IRIS does not read page contents, browsing history, clipboard text, passwords or wallet secrets. It has no website access permissions and uploads no scan data to an IRIS server. When connected, the IRIS website can read this browser’s extension report directly. Anyone using this browser profile can open its local review. Disconnect to stop sharing with the website.

The report reflects permissions reported by your browser. Site restrictions may narrow access. This is an access review, not a malware verdict. Individual site access can be changed in your browser’s extension settings.
