Privacy, permissions and what this check covers

IRIS uses the browser’s management permission to list extensions and perform changes you choose here. Storage remembers your review choices, reversible changes and optional web connection in this browser profile.

IRIS does not read page contents, clipboard text, passwords or wallet secrets. It has no page-content access permissions and uploads no scan data to an IRIS server. The optional history permission is used only when you start a recent-browsing check. Saved checks expire after 7 days and are removed when the companion next runs; raw history URLs are not saved by IRIS. When connected, the IRIS website can read this browser’s extension report, monitoring status and recent-check counts directly. Matched history-check domains are not shared. Live scam warnings share only their hostname, time and whether a page was blocked or already open. Anyone using this browser profile can open its local review. Disconnect to stop sharing with the website.

The report reflects permissions reported by your browser. Site restrictions may narrow access. This is an access review, not a malware verdict. Individual site access can be changed in your browser’s extension settings.
