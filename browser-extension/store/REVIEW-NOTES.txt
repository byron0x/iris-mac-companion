IRIS browser companion 0.4.0 update

New: connected account plans and clearer plan status. Free: one manual browser scan per UTC calendar month. Pro: unlimited scans, opt-in extension-change badges and known-scam protection. Saved review, trust, disable/restore/removal, and local link checks remain available on Free. No new extension permissions. CSP allows the fixed IRIS plan API in addition to the existing GitHub feed.

To test: install and open the companion. Check link works without sign-in: enter https://example.com (no match is explicitly not a safety verdict). Choose Connect to IRIS; allow sharing, then sign in to the dashboard with a Google account or wallet. The dashboard completes a one-time connection and shows IRIS account connected. Return to the companion and choose Scan my browser. Optional history access is requested only by this click. Declining it still runs the extension portion with explicit partial coverage. Keep or turn off an ordinary extension, then restore it. Removal uses Chrome's own confirmation. A second complete Free scan shows the monthly limit while saved cleanup remains available.

IRIS Pro is an optional subscription purchased on the website. It enables repeated scans and opt-in live protection. The UI discloses this before a user grants navigation access. Account checks carry a random credential and scan-attempt ID only. No browser report is uploaded to the account server. Expired or unverifiable access pauses monitoring. Previously installed rules remain during a brief five-minute verified-access window; no remote code is executed.

History is processed locally on demand (up to 5,000 entries from seven days). Matched hostnames stay local; connected web displays counts only. History results expire after seven days. Live warning activity stores at most 100 hostname/time/status records for 30 days; these can appear directly in the connected web dashboard. No page text, wallet transactions, seed phrases, passwords, normal navigation stream, or clipboard contents are collected. Scan and pairing behavior can be tested with any Google or wallet account; no IRIS-specific password is required.

ScamSniffer's public feed updates daily when protection is on but has a seven-day source delay. No match does not certify safety. No threat visit proves device infection.
